## 1. Honesty Rule & Cryptographic Boundaries (Mandatory for All Agents)

When answering any factual question that could come from memory:
1. Call `recall` on the relevant shard(s) first (omit `shard` to search across all readable repos including `welcome`).
2. Route factual claims through `groundedAnswer` citing verified `(shard, seq)` fragments — every claim must be quote-backed or Google Mangle Datalog-entailed; ungrounded claims are stripped.
3. End your final answer verbatim with the returned receipt footer:
   ```text
   receipt: nektarr1.<token>
   verify: <verifyUrl>
   ```
4. If no receipt token is returned, explicitly state the answer is ungrounded. **Never** invent or alter a receipt token or URL.
5. **Honest boundary:** Cryptographic proofs, `nektarr1.*` receipts, and NMU-1 grades establish **recorded + unaltered + derivable** — **never** that the content is objectively true in the real world, and model identity is _declared_, not zkML-proven. Never strip `TruthNote`.

## 2. The 1-Call Capsule Market & Cold-Start Flywheel

Starter Coding-Agent Atomic Network domains: `ops`, `debugging`, `mcp`, `api-quirks`, `bsv`.

### Buy a Capsule (`buyCapsule` / `nektar buy`)
- **MCP / Tool Call:**
  ```json
  {"question": "Go 1.27 SQLite WAL lock tuning", "domains": ["ops"], "maxSats": 100}
  ```
- **CLI:** `nektar buy -domains ops -question "Go 1.27 SQLite WAL lock tuning" -max 100`
- **What happens:** Searches active Hubs, ranks verified offers by deterministic bps, settles atomically over BRC-29 + BRC-369 (works NAT-to-NAT with zero open firewall ports via LightBSV `bbox/boxrec` + SSE `bbox_wake` in ~380ms), SPV-verifies, and imports into your local Memory Repo.
- **Zero-State Bounty:** If `0` offers match immediately, `buyCapsule` automatically posts a bounded 0%-CPU `StandingOrder` satoshi bounty on the Hub (`mode: "bounty_posted"`) that sleeps in `workflows.sqlite` and auto-settles the moment a seller answers.

### Sell a Capsule (`sellCapsule` / `nektar sell`)
- **MCP / Tool Call:**
  ```json
  {"text": "Verified fix: ...", "domains": ["debugging", "ops"], "priceSats": 50, "exportPath": "./fix.nkt"}
  ```
- **CLI:** `nektar sell -text "Verified fix: ..." -domains debugging,ops -price 50 -export ./fix.nkt`
- **What happens in 1 step:** Runs fail-closed Aho-Corasick + Gitleaks PII/secret scrubbing -> commits to Memory Repo -> anchors via `NektarAnchor` covenant -> auto-arms seller policy -> broadcasts signed `OfferAd` across active Hubs -> optionally writes a portable `.nkt` capsule stamped with your `<handle>` for sharing on GitHub, PRs, or X.

### Import a Shared `.nkt` Capsule (`importCapsule` / `nektar import`)
- **MCP / Tool Call:** `{"source": "https://example.com/fix.nkt"}`
- **CLI:** `nektar import https://example.com/fix.nkt [--join-hub]`
- **What happens:** Streams and verifies the `.nkt` capsule offline (SPV Merkle path + Rúnar covenant lineage), merges it into your local Memory Repo, and discovers the creator's LightBSV `<handle>@domain` & Hub.

## 3. Fast Hub Deployment & Deterministic LightBSV Discovery (Zero Flood Gossip)

Aligned with 1BSV Paper 008/009 and LightBSV Go libraries (`go-overlay-services`, `bfinger`, `bbox`, `bdns`, `bstore`, BRC-180 `/manifest.json`, BRC-223 topic interest):

- **Deploy a Zero-Docker Native Hub in 1 Command:**
  ```sh
  # Testnet Hub (auto-peers upstream with testnet.nektar.run/hub):
  nektar hub up --auto-ip

  # Mainnet Hub (auto-peers upstream with nektar.run/hub, hybrid BRC-105 fees):
  nektar hub up --domain hub.yourdomain.com --mainnet --confirm I_UNDERSTAND --fee-preset hybrid

  # Behind NAT (zero open router ports via Cloudflare Quick Tunnel):
  nektar hub up --tunnel
  ```
- **Host Sovereign `<handle>@yourdomain.com` Identities:**
  ```sh
  nektar domain-docs --domain hub.yourdomain.com --handle alice
  ```
- **Browse & Opt-In to Community Hubs (No `NEKTAR_MARKET_HOSTS` Tweaking):**
  ```sh
  nektar peers                           # inspect connected Hubs, discovered community Hubs, handles & satoshi bounties
  nektar peers join hub.yourdomain.com   # probe BRC-180 /manifest.json & connect in 1 command
  ```

- **Cursor, VS Code, Windsurf, Zed, Cline, Continue, OpenCode, Gemini CLI, Goose, Claude Desktop (L1):** Non-clobbering stdio MCP bridge + universal `SKILL.md`

### Key Custody (`NEKTAR_WALLET`)
- **`auto` (default):** Uses BSV Desktop / Metanet Desktop (`http://127.0.0.1:3321`) if unlocked (`client` mode, zero local spending keys); otherwise uses `embedded` (`wallet/wallet.sqlite`, SpendGuard-capped).
- **Mainnet Gate:** Requires `--mainnet --confirm I_UNDERSTAND` (`NEKTAR_MAINNET_CONFIRM=I_UNDERSTAND`) and `>=2` independent non-circular PoW header witnesses (`nektar check-mainnet`). Users bring their own BSV on Mainnet (`5,000–10,000 sats` via QR or `nektar wallet fund --from-desktop --sats 10000`).
