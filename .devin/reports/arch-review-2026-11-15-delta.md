**Date:** 2026-11-15 · **Scope:** `ef8b4e5..HEAD` — 21 commits, 35 files, +754/−184, perf/liveness hardening across automation, bstack, chain, mcp · **Baseline:** `arch-review-2026-11-13.md` (full review) + `tools/.arch-baseline.json` re-baselined in `2b8dde0` (this delta)
**Method:** scoped delta pass per `.devin/skills/arch-review` — measured against the 11-13 report's findings/expectations, not a fresh whole-system review.

Deploy: WoC→bananablocks on the testnet sandbox; serial workspace build for the OOM'd deploy box.

### Improvements confirmed (vs 11-13 expectations)

- **Second write path eliminated (F7/F10):** `ChainIndex.broadcast` deleted from the interface (indexer.ts) — the index is *structurally* read-only now; `mainnet.ts`'s WoC detour is gone; "broadcaster is the only write path" moved from convention to **type-enforced**. This kills the "error reported while tx actually aired" submission_unknown class at the source. The strongest move in the delta.
- **Reconcile paths added where the 11-13 hunt predicted wedges (F3/F11):** tombstone sweep heals orphaned spent-marks (the `TX_MISSING_PARENT` / killed-process class — rhymes with the proven ghost-parent incident); aired-tx lease release at every transition site; finger journal walk-back re-anchors to a live head; `fundingTxid` + enrich-on-read + a one-time knex migration heals pre-migration rows instead of re-serving stale ancestry forever; `republishOne` fixes the input-0 assumption (`inputs.find` — real bugfix).
- **Lifecycle hardening (F2):** `rt.stopped` bails between upkeep phases + `upkeepRun` dedup/stop-guard + `deals`/`upkeep` split so a grinding housekeeping pass can't hold the want-collect window hostage; pass-phase timing logs (partial answer to the silence problem — a >2s pass now names the phase that ate it).
- **Bounded retry where there was none (F9):** `starveBounce` bounds starvation retries inside `STATE_LIMITS.funding.maxAgeMs` via durable `fundingSince`/`fundingTries` in op.data — survives restart, terminal on exhaustion.
- **11-13 findings:** F7 (unbounded drain-spin at automation/runtime.ts:1105) **not touched** — still unbounded, though partially de-fanged (post-stop `upkeep()` can't queue new work). F2/F3/F6 (txStatus ×3, gorillapool ×5, single status source) **not touched** — though the new `liveSet` index listing is incidentally a second read source for custody truth. F5 **worsened slightly** (+2 dialects). F4 type-cycles/F10 dual-open **already resolved** before this delta (`@nektar/memory` exists; AGENTS.md records `openLiveRuntime` gone — mcp is 9,514 vs 9,977 at 11-13).

### Verdict

**The delta improved the system's architectural position — net-positive, but it added a real regression and a new unenforced-invariant class in exchange.** Against the 11-13 report's expectations it delivers on three of its asks in spirit: the ambient "wedges that never heal" class (leases on aired txs, orphaned tombstones, stale journal ancestry, dead finger heads) got reconcile paths instead of remaining silent leaks; the "second write path" trust hole closed *structurally* (index broadcast deleted from the type, not just discouraged); and lifecycle got `rt.stopped` bails + a deals/upkeep scheduler split that directly addresses the teardown-write hazard. Layering is exemplary — zero new cross-package edges, and the enrich seam is dependency-inverted rather than letting bstack reach for chain. The costs are concentrated and nameable: **D1 is a genuine regression** — `leaseLive` forgot the `'released'` arm while fixing the take/prepare divergence, so the very wedge it documents can still occur (permanently, when no tx row exists); **D3 escalates a pushed status word into a custody write** — correct trade-off per the comments, but the honesty bar deserves first-party corroboration before it heals; **D6** is the new S2 — five optional oracle seams whose correctness contracts live only in doc comments, the fastest-growing unenforced-invariant surface in the diff; and the Funds interface is accreting (7 late-bound optional fields now), pushing `chain` past 5k LOC as a leaf package. The 11-13 structural agenda (types leaf, open-path convergence, chain-observer seam, `withRetry` consolidation) went untouched — this delta chose liveness over debt, which was defensible: it converts several documented-incident-shaped stalls into self-healing flows. Fix order: D1 first (it's a named production-wedge regression on the money path), then D2/D6 as cheap guardrails before the oracle surface spreads further.
