## 0. Honesty Rule & Cryptographic Boundaries (Mandatory for All Agents)

When answering any factual question that could come from memory:
1. Call `recall` on the relevant shard(s) first (omit `shard` to search across all non-system shards/repos, including `welcome`).
2. Route factual claims through `groundedAnswer` citing verified `(shard, seq)` fragments — every claim must be quote-backed or Google Mangle Datalog-entailed; ungrounded claims are stripped.
3. End your final answer verbatim with the returned receipt footer:
   ```text
   receipt: nektarr1.<token>
   verify: <verifyUrl>
   ```
4. If no receipt token is returned, explicitly state the answer is ungrounded. **Never** invent or alter a receipt token or URL.

**What proofs establish vs. what they never establish:**
- Cryptographic proofs, `nektarr1.*` receipts, `EdgesRoot` sidecars, and NMU-1 commodity grades establish that a memory was **recorded, unaltered, derivable, schema-conformant, verbatim-cited, bonded, and live-maintained** — **never** that the content is objectively true in the real world.
- Model identity (`modelId`, Jev extraction confidence/margin/support bps) is **declared provenance**, not zkML-proven.
- Never strip `TruthNote`, `AdvisoryNMUNote`, `AdvisoryExtractionNote`, or `AdvisoryBridgeNote`.

## 1. Plain-English Architecture & Concept Map

- **Brain / Node:** Local single-binary daemon (`http://127.0.0.1:18420`, pure-Go SQLite `modernc.org/sqlite`, zero CGO). All docked AI apps share this brain with zero lock contention.
- **Dock:** Non-destructive 1-click wiring of local AI apps (Claude Code, Cursor, VS Code, Codex, Windsurf, Zed, Cline, Claude Desktop, Hermes, OpenClaw). Fully reversible via `nektar dock --uninstall`.
- **Shard / Memory Repo:** A topic-scoped, Git-compatible, BSV UTXO-anchored memory repository (`CommitObject`, `TreeObject`, `BlobObject`, branches, tags, diff, blame, 3-way merge, `.nkt` CHIRP Capsules). **Private by default** via CLKA encryption at rest unless explicitly `public: true` or listed for sale.
- **Fragment vs. Verified Triple:** A **Fragment** is a committed note/file. A **Verified Triple** `(subject, predicate, object)` is one canonical knowledge unit (`TagTripleV1` CBOR hash), validated against a committed domain Ontology (`ont-<domain>`).
- **Anchor & Receipt (`nektarr1.*`):** Anchoring commits a shard's Merkle root on BSV via the `NektarAnchor` Rúnar head-UTXO covenant (strict append-only succession). Receipts cryptographically bind answers, cited leaves, rules, and SPV proofs.
- **Sats & Atomic Swap:** Sub-cent BSV micropayments (`100 sats` < 0.01¢). Payment (BRC-29 AtomicBEEF or `DisclosureSale` BIP-199 escrow) and BRC-369 content-key reveal settle atomically.
- **Hub (Spine-and-Leaf Overlay):** Stateless/durable BRC-22 `/submit` & BRC-24 `/lookup` relay mounting Nektar's 16 market lanes (`tm_nektar_<net>_0..f` / `ls_nektar`), SSE `/events`, NAT-safe `/bbox` relay, and Lightweb Go modules (`bfinger`, `bbox`, `blogs`, `borg`, `bsecret`, `bstore`). Hubs never hold user private keys or unencrypted private shards.
- **Operator Policy, SpendGuard & Kill Switch:** Hard fail-closed per-tx fee caps, per-deal caps, daily spend caps, 0-conf limits, and instant emergency kill switch (`NEKTAR_KILL=1`, `<dataDir>/KILL`, or `POST /v1/automation/kill`).
- **SleepCycle & PII Gate (`internal/distill`):** Idle background distillation that runs fail-closed secret/PII scrubbing (gitleaks + regex), extracts verified JevGraph triples, enforces `usageRights` on purchased (`Tainted`) fragments, and prepares clean `market-*` shards.

## 2. Bootstrap, Install & Key Custody

### Fast Install (25 Seconds, Zero Docker, Zero Node.js)
```sh
# macOS & Linux (default: testnet with built-in free test sats)
curl -fsSL https://raw.githubusercontent.com/kryptokrates/nektar/master/install/install.sh | sh -s -- --up

# BSV Mainnet (explicit opt-in required)
curl -fsSL https://raw.githubusercontent.com/kryptokrates/nektar/master/install/install.sh | sh -s -- --up --mainnet --confirm I_UNDERSTAND
```
```powershell
# Windows (PowerShell)
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/kryptokrates/nektar/master/install/install.ps1))) -Up
```
```sh
# Docker (GHCR)
docker run -d --name nektar --restart unless-stopped \
  -p 127.0.0.1:18420:18420 -v nektar-data:/data \
  ghcr.io/kryptokrates/nektar:latest serve
```

What `nektar up` does automatically:
1. Installs the static `nektar` binary and acquires an OS advisory instance lock.
2. Starts the background daemon (`http://127.0.0.1:18420`, recorded in `~/.nektar/active-daemon.json`) and auto-supervises `restate-server` v1.8.1 for durable market workflows.
3. Auto-docks installed AI apps non-destructively.
4. Seeds the `welcome` shard and runs a live `nektarr1.*` receipt probe.

### Key Custody Modes (`NEKTAR_WALLET`)
- **`auto` (default):** Uses BSV Desktop / Metanet Desktop (`http://127.0.0.1:3321`) if running and unlocked; otherwise uses `embedded`.
- **`embedded`:** Pure-Go BRC-100 SQLite wallet (`internal/wallet`, backed by `NEKTAR_DATA_DIR/wallet/wallet.sqlite`) with BRC-43/BRC-29 key derivation, UTXO basket/pool management (`fuel`, `reserve`, `default`, plus asset baskets), and ARC/BEEF broadcast reconciliation. Raw private keys never leave `internal/wallet`.
- **`client`:** `lightwebinc/bcommon/wirewallet` over loopback `http://127.0.0.1:3321` (BSV Desktop / Metanet Desktop) — zero spending keys ever touch Nektar. Refused on `memory`/`regtest`.
- **Mainnet Safety Gate:** Mainnet refuses to boot or spend without `NEKTAR_MAINNET_CONFIRM=I_UNDERSTAND` and >=2 independent non-circular PoW header witnesses (`nektar check-mainnet`).

## 4. Memory, Privacy, Encryption & Git-Compatible Memory Repos

- **Private-by-Default CLKA Encryption (`internal/lattice`):** Non-system fragments are CLKA-encrypted at rest by default (`public: true` opts out). Supports downward-only clearance bundles (`provisionClearance`, optionally ECDH-sealed to a recipient pubkey) and forward-secret epoch rotation (`rotateLattice`).
- **BRC-369 Borg Group Encryption (`internal/bstack`):** Multi-party group shards (`borgGroup`) with epoch key sealing and member revocation rotation (`borgGroup` tool: `create | add | revoke | get`).
- **Git-Compatible Memory Repos (`internal/memrepo`):** Every shard is a content-addressed commit DAG (`CommitObject`, `TreeObject`, `BlobObject`) with pure-Go `go-git/v5` projection, unified diff, line-level blame, 3-way diff3 auto-merge, branches (with BRC-43 derived genesis keys), signed tags, volumetric BRC-167 CHIRP blobs (`chirpUrl` / `blobBase64`), and real `.git` workspace checkout (`nektar repo checkout`).
- **Self-Verifying `.nkt` CHIRP Capsules:** `nektar repo export` / `import` / `verify` package commits, trees, blobs, sidecars, and NektarAnchor SPV proofs for offline verification.
- **Knowledge DAG & Bi-Temporal Supersession:** Fragments carry typed `modality`, signed `refines` / `supersedes` edges (`lineage` tool), and trigger real-time `SupersessionEvent` hooks for Grade S live feeds.
- **Right-to-Forget (`forget`):** Atomically shreds local plaintext, ciphertext, `knowledge_edges`, `fragment_graph_meta`, `fragment_nmu_meta`, and public `graph/*.edges.json` sidecar blobs while preserving on-chain Merkle commitments.
- **O(log N) MMR Proofs:** `compactProve` builds a compact proof directly against the head `NektarAnchor` UTXO; `consistencyProof` proves batch `fromN` is an unaltered prefix of batch `toN`.

## 5. RFC-001: JevGraph Native Ontologies & Cross-Ontology Bridge Shards

Normative spec: https://raw.githubusercontent.com/kryptokrates/nektar/master/docs/rfcs/RFC-001-jevgraph-ontology.md

- **Committed Domain TBox (`ont-<domain>/ontology.yaml`):** YAML/JSON schema declaring `classes` (with `parent`, `disjointWith`, `definition`), `relations` (with `domain`, `range`, `parent`, `inverseOf`, `transitive`, `functional`, `symmetric`), `axioms`, optional local `entities` (gazetteer aliases/RE2 patterns), and local integer-bps `thresholds`.
- **Canonical `OntologyID` Invariance:** `DSHA256(TagOntologyV1 || CanonicalJSON(TBox))` — excludes local `entities` and `thresholds` so independent peers sharing one vocabulary produce identical 64-hex wire IDs.
- **4-Stage Bounded Extraction (`internal/jevgraph`):**
  1. $O(nk)$ sentence segmentation (exact UTF-8 byte offsets) + Unicode word-boundary mention matching + typed pair blocking.
  2. Optional self-hosted open-weight System-1 Jev evaluator (`NEKTAR_JEV_*`) running closed-set Choice + Noul negation checks (quantized to integer bps `0..10000`). Degrades cleanly to `status: "review"` (`jev_offline`) if offline, or fails closed under `-ontology-strict`.
  3. Deterministic Google Mangle Datalog consistency gate (domain/range, disjointness, functional cardinality).
  4. Triage (`accepted | review | rejected`), `OntologyGapSignal` emission, and Merkle `EdgesRoot` bound into L1 MPE (`ontologyId`, `edgesRoot`) + `graph/<path>.edges.json` sidecar (for explicitly `Public` fragments only; encrypted CLKA/Borg fragments never leak plaintext sidecars).
- **Cross-Ontology Bridge Shards (`bridge-<src>-<dst>`):** Aligns two TBoxes via `owl:equivalentClass`, `rdfs:subClassOf`, `owl:equivalentProperty`, `rdfs:subPropertyOf`, `skos:exactMatch` (`skos:closeMatch` is intentionally non-entailing), compiled into Mangle rules and used by `GroundedAnswer`, `VerifyReceipt`, and `StandingOrder` (`allowBridge: true`).

## 6. RFC-002: Nektar Memory Unit Standard (NMU-1)

Normative spec: https://raw.githubusercontent.com/kryptokrates/nektar/master/docs/rfcs/RFC-002-nmu1-commodity-standard.md

NMU-1 standardizes AI memory as a machine-verifiable commodity with **zero floating-point arithmetic**:

- **Canonical Unit (`UnitCount`, `0..4096`):** 1 Verified Triple. `CountVerifiedTriples` deduplicates via canonical `TagTripleV1` CBOR hashes, restricts counted triples to predicates declared in the pinned `OntologyManifest`, and caps counted triples at `8` per `(subject, predicate)` pair to prevent semantic triple stuffing.
- **Normalized Unit Rate (`satsPer1kUnits`):** Exact 128-bit overflow-safe integer milli-sats per verified triple: `floor((priceSats * 1000) / max(1, unitCount))` (clamped to `>= 1` for non-zero prices). Formatted as decimal `sats/triple` (e.g. `2500` = `2.5 sats/triple`).
- **Machine-Verifiable Grades (`C < B < A < S`):**
  - **Grade C (Raw Scrubbed):** Passed fail-closed PII/secret scrub gate.
  - **Grade B (Distilled & Ontology-Pinned):** Grade C + `Distilled` + 64-hex `OntologyID` + `>= 1` verified unique TBox triple + Mangle consistent.
  - **Grade A (Bonded & Cited):** Grade B + verbatim source spans bound in L1 MPE (`EdgesRoot`) + active, unseized `NektarCheckpointBond` collateral.
  - **Grade S (Live Maintained):** Grade A + active SSE supersession feed pushing bi-temporal `core.RefinementSupersedes` updates.
  - **Grade S Dead-Feed Guard:** `RankOffersWith6DReputationAt` awards full `+1300 bp` Grade S bonus only with an active bond AND non-penalized `DispBP >= 5000` & `CollabBP >= 5000`. Buyer SSE client (`StreamShardSubscription`) auto-emits `DispBP <= 2500` / `CollabBP <= 3500` slashing `nektarrep1.*` attestations if a paid feed 404s/5xx or drops before `expires_at`.
- **Freshness & Usage Rights:**
  - `freshnessClass`: `ephemeral` (TTL via `validUntilUnix`), `versioned` (`subjectVersion`, e.g. `go-1.27`), or `evergreen`. Expired items (`validUntilUnix > 0 && now >= validUntilUnix`) are excluded fail-closed.
  - `usageRights`: `inference_only` (default, fail-closed — blocked from SleepCycle distillation/resale) or `distill_resellable` (may be distilled into derived shards with a `RefinementRefines` provenance edge).
- **Multi-Mode Market Contracts (Simultaneous on Any Listing):**
  - `spot` (`priceSats > 0`, optional `pricePerUnit: true`): Atomic FactPack purchase via BRC-29 + BRC-369 / `DisclosureSale`.
  - `per_query` (`queryPriceSats > 0`): Metered recall at `POST /v1/market/query` over BRC-105 HTTP 402 returning verified items + signed `nektardr1.*` receipt.
  - `subscription` (`subscriptionPriceSats > 0`, `subscriptionDurationSec`): Activated via BRC-105 HTTP 402 at `POST /v1/market/subscriptions`; streamed via `GET /v1/market/feeds/{shard}` with `±60s` replay-protected ECDSA headers (`X-Nektar-Sub-ID`, `X-Nektar-Pub`, `X-Nektar-TS`, `X-Nektar-Sig` over `DSHA256("nektar:feed-auth:v1" || "GET|/v1/market/feeds/{shard}|{subId}|{ts}")`).
- **Non-Repudiable Receipts, Quarantine & Slashing:**
  - `DealReceipt.CanonicalFields()` binds `nmu_*` commercial terms into `nektardr1.*` MPE `FieldsRoot`.
  - Post-reveal `VerifyDeliveredGrade`: if a seller inflates grade or unit count, the buyer stores the paid plaintext tagged `GradeMismatch: true` for audit, **quarantines untrusted edges out of `knowledge_edges` by default**, and emits a signed `nektarrep1.*` slashing attestation.
- **Commodity Ticker:** `GET /v1/market/ticker`, CLI `nektar ticker`, MCP `marketContract` (`action: "ticker"`), and Dashboard `/state.ticker` group live quotes by `(ontologyId, grade, pricingMode)`.

## 7. Autonomous Market, Restate Durable Workflows, 6D Reputation & Covenants

- **16-Lane Overlay Wire (`nkt1` CBOR):** Topics `tm_nektar_<net>_0..f` and lookup service `ls_nektar` (supports `ontologyId`, `minGrade`, `maxSatsPer1kUnits`, `freshnessClass`, `requiredRights`, `pricingMode` filters). Fail-closed admission rejects malformed NMU/ontology payloads.
- **Restate v1.8.1 Durable Execution (`internal/market`):** Sole live-network deal engine running `BuyerDeal`, `SellerDeal`, `StandingOrder` (0%-CPU durable limit orders for knowledge, live-steerable via `watchKnowledge`), `EscrowGuardian`, `AnchorCadence`, and `Custody`.
- **6D Reputation & EigenTrust (`internal/reputation`):** Per-ontology 6-axis scorecards (`AccBP`, `ConsBP`, `DispBP`, `PredBP`, `CollabBP`, `ProvBP` in `0..10000` bps) updated from verified `nektarrep1.*` attestations tied to `nektardr1.*` receipts.
- **Rúnar BSV Covenants (`internal/contracts`, precompiled & `//go:embed`):**
  - `NektarAnchor`: Head-UTXO append-only lineage (`n -> n+1`, `R`, `R'`, owner key rotation).
  - `DisclosureSale`: BIP-199 hash-locked atomic key-reveal escrow with height-gated buyer refund.
  - `NektarAgentVault`: On-chain rolling-window & per-tx spending cap vault (`nektar vault`).
  - `NektarCheckpointBond`: On-chain time-locked seller collateral bond (`nektar bond`) required for NMU-1 Grades A & S.

### Unattended Mainnet Autonomy & Operational Hardening
- **SNTP Clock-Skew Guard & Anomaly Circuit Breaker (`internal/autonomy`):** Queries 3 independent SNTP pools (`github.com/beevik/ntp`, median offset with automatic HTTP `Date` fallback when UDP/123 is blocked). Warns at `>=15s` drift and **pauses autonomous spending fail-closed** at `>=25s` (well inside the `±60s` Grade S SSE replay guard), requiring 2 consecutive `<10s` checks to recover. Pairs with `github.com/sony/gobreaker/v2` circuit breakers that trip on consecutive autonomous spend failures, dead-feed slashing bursts, or misbehaving `per_query` peer sellers; wired directly into `SpendGuard`, `nektar doctor`, `/state`, `/v1/metrics`, and `POST /v1/autonomy/reset`.
- **Reboot-Resilient Grade S Subscription Supervisor (`internal/market`):** `github.com/thejerf/suture/v4` supervision tree + `github.com/cenkalti/backoff/v5` jittered exponential reconnects reload all active unexpired buyer subscriptions from SQLite (`user_version = 10`) on boot/wake, resume from persisted `last_seq`, apply `fragment_distilled` and `fragment_superseded` locally without duplicates, and emit `nektarrep1.*` dead-feed slashing attestations if a paid seller vanishes before `expiresAt`.
- **Opt-In `per_query` 402 Buyer Recall Fallback (`internal/market/query_client.go`):** Disabled (`false`, fail-closed) by default. When explicitly enabled (`NEKTAR_AUTO_QUERY_ON_MISS=1`, `POST /v1/autonomy/config`, or per-call `allowMarketFallback: true`), local recall misses automatically query top-ranked `per_query` sellers over BRC-105 HTTP 402 within `SpendGuard` & `maxAutoQuerySats` caps, verify seller identity (anti-MITM), `DealReceipt`, and offline SPV `ProofBundle`, scrub text, and cache results locally marked `Tainted: true` with `usageRights` preserved.
- **Closed-Loop `SleepCycle` Supply/Demand Triggers:** Demand-prioritizes working shards matching recent overlay `unmatched_wants` before alphabetical distillation, re-announces newly listed `market-*` shards to Hubs, and (strictly opt-in via `NEKTAR_AUTO_WANT_ON_MISS=1` / `autoWantOnMiss: true`) promotes repeated local `recall_misses` into bounded 24h `StandingOrder`s / `WantAd`s with daily count and satoshi caps.
- **BRC-42 Envelope-Encrypted State Backups (`internal/backup`):** Scheduled WAL-safe `VACUUM INTO` snapshots of `nektar.sqlite` + embedded `wallet/wallet.sqlite` + `spend-guard.json` compressed with pure-Go `zstd` (`github.com/klauspost/compress/zstd`) and encrypted with AES-256-GCM using an ephemeral 32-byte DEK wrapped via BRC-100 `wallet.Encrypt` (works across both `embedded` and BSV Desktop `client` custody; raw private keys never leave `internal/wallet`). Writes atomically to local directories (`NEKTAR_BACKUP_DIR`) or any S3 / Cloudflare R2 / Backblaze B2 / MinIO bucket via zero-dependency stdlib AWS SigV4 (`NEKTAR_BACKUP_S3_BUCKET`) with retention pruning.
- **Cross-Platform OS Daemon Supervision (`nektar service`):** Powered by pure-Go `github.com/kardianos/service`, installing and controlling native `systemd` (Linux), `launchd` (macOS), and Windows Services with restart-on-failure and `--confirm I_UNDERSTAND` mainnet gating.

- `recall` — Recall Cedar-authorized, CLKA/Borg-decrypted fragments (`shard`, `branch`, `atCommit`, `query`, `verifySpv`, `limit`, optional opt-in `allowMarketFallback`, `maxFallbackSats`).
- `forget` — Atomically shred local plaintext, ciphertext, edges, and metadata (`shard`, `seq`).
- `groundedAnswer` — Verify claims via quote + Google Mangle Datalog + ontology/bridge rules, strip hallucinations, return `nektarr1.*` receipt & verify footer.
- `verifyReceipt` — Offline verify `nektarr1.*` token, §16 delegations, `RuleRef`s, and SPV settlement status.
- `repo` — Full Git-compatible Memory Repo tool (`action: list|log|show|tree|read|diff|blame|verify|commit|rm|branch|fork|merge|cherryPick|revert|tag|export|import|prove|rotate`).
- `ontology` — Manage domain TBox ontologies, Bridge Shards & JevGraph extraction (`action: init|list|show|validate|extract|edges|review|align`).
- `lineage` — Inspect verified cryptographic Knowledge DAG (`shard`, `seq`).
- `want` — Buy verified knowledge live (`domains`, `question`, `ontologyId`, `maxSats`, `minGrade`, `maxSatsPer1kUnits`, `freshnessClass`, `requiredRights`, `pricingMode`, `targetShard`, `standingTtlSeconds`).
- `watchKnowledge` — Create, list, live-steer, or cancel durable 0%-CPU Restate `StandingOrder`s (`action: create|list|steer|cancel`, full NMU-1 & ontology/bridge filters).
- `sell` — Arm a local shard for multi-mode NMU-1 selling (`shard`, `domains`, `priceSats`, `pricePerUnit`, `queryPriceSats`, `subscriptionPriceSats`, `subscriptionDurationSec`, `freshnessClass`, `usageRights`, `minAdvertisedGrade`, `ontologyId`, `dynamicPricing`, `allowRaw`) or submit to a Hub bounty (`bountyId`, `hubUrl`, `seq`).
- `marketContract` — Query standardized NMU-1 Commodity Ticker or manage paid shard feed subscriptions (`action: ticker|subscriptions|revokeSubscription`).
- `deals` — List persisted deals, pending operator approvals, sell listings, 6D reputations, liquidity & matcher metrics.
- `fund` — Wallet funding address, confirmed/unproven/reserved balance, UTXO pools, SpendGuard caps, BEEF/txid import, optional testnet faucet drip.
- `doctor` — Full node self-diagnosis (SQLite, wallet, Restate, hosts, peers, policies, SSE health) + next steps.
- `peers` — Signature-verified peers, bfinger handles, sell domains, CHIRP packs, and open Hub bounties.
