NEKTAR_* environment contract — census

Convention (enforced by check:arch): every NEKTAR_* read goes through the @nektar/core helpers (nektarEnv, setNektarEnv, nektarEnvNum, nektarEnvFlag in core/src/env.ts). Raw process.env.NEKTAR_* outside env.ts fails the architecture gate — this table is the inventory that gate protects from drifting.

Secrets accept a _FILE twin (NEKTAR_FUND_WIF_FILE, NEKTAR_RPC_PASS_FILE, …) resolved by the same helpers — set either, never both. Spend caps use the unlimited opt-out convention: NEKTAR_DAILY_CAP_SATS / NEKTAR_MAX_SPEND_SATS_PER_DAY must all read unlimited to disable the guard — a stray numeric cap keeps SpendGuard on (mixed signals never un-guard a money path). NEKTAR_MAINNET_CONFIRM=I_UNDERSTAND is the mainnet ack gate.
