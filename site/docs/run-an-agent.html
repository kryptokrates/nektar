Run Your Own Agent

Run a sovereign Nektar AI memory agent on your laptop or 24/7 server — with non-custodial key separation, Restate v1.8.1 crash-safe deals, and hard SpendGuard caps.

1. Personal vs. 24/7 Server 2. Small-Sats Mainnet Canary 3. Built-In Autonomy 4. Cold/Hot Custody & Kill Switch

1. Personal Machine vs. 24/7 Headless Server

Every Nektar agent owns its own local encrypted SQLite brain (~/.nektar/main on Mainnet, isolated from Testnet) and connects to any MCP, A2A, or OpenAI/Anthropic client.

Personal Laptop (Attended)

  • Use BSV Desktop / Metanet Desktop on loopback 127.0.0.1:3321 with --wallet client — zero raw spending keys live inside Nektar.
  • Best for daily coding with Claude Code, Cursor, Codex, and Hermes while keeping full wallet approval in your desktop app.
  • One-command start: nektar up --network main --confirm I_UNDERSTAND --wallet client.

24/7 Headless Agent (Server / VPS)

  • Use --wallet embedded (pure-Go BRC-100 SQLite wallet; raw private keys never leave internal/wallet).
  • Keep only a tiny hot float (5,000–25,000 sats) funded from your desktop and sweep earnings back anytime.
  • Pair with pinned restate-server v1.8.1 (NEKTAR_RESTATE_REQUIRED=1) so in-flight trades survive restarts and power cuts.

Funding & Sweeping Between Desktop and Headless Agent

bash
# Fund a headless hot agent from BSV Desktop
nektar wallet fund --from-desktop --sats 25000

# Sweep accumulated earnings back to cold storage or BSV Desktop
nektar wallet sweep --to-desktop --network main --confirm I_UNDERSTAND

2. Small-Sats Mainnet Canary (5,000–10,000 Sats)

Before giving an autonomous agent a larger budget, validate everything end-to-end with 5,000–10,000 real sats (~$0.003). Mainnet fails closed unless NEKTAR_MAINNET_CONFIRM=I_UNDERSTAND is set and at least 2 independent, non-circular PoW header witnesses are healthy (default 2-of-3 quorum: WhatsOnChain + official US & EU BSV Association Arcade v2).

bash
export NEKTAR_NETWORK="main"
export NEKTAR_MAINNET_CONFIRM="I_UNDERSTAND"
export NEKTAR_HEADERS_SOURCE="woc:main,arcade:https://arcade-v2-us-1.bsvblockchain.tech,arcade:https://arcade-eu-1.bsvblockchain.tech"
export NEKTAR_SETTLE_SPEC="broadcaster:main"
export NEKTAR_MAX_FEE_SATS_PER_TX=2000
export NEKTAR_MAX_SPEND_SATS_PER_DAY=10000
export NEKTAR_RESTATE_REQUIRED=1

# 1. Verify Mainnet safety gates (exits 0)
nektar check-mainnet

# 2. Boot agent + Restate v1.8.1 and inspect health
nektar up --network main --confirm I_UNDERSTAND
nektar doctor --network main

# 3. Get Mainnet deposit address & fund with 5,000-10,000 sats
nektar wallet address --network main --qr
nektar wallet sync --network main

# Save and anchor a fragment on Mainnet

# After 1 mined block (~10 min), sync and run full offline SPV verification
nektar wallet sync --network main

3. Built-In Autonomy (Zero Babysitting)

  • Crash-Safe Durable Trades (Restate v1.8.1): BuyerDeal, SellerDeal, StandingOrder, AnchorCadence, and Custody workflows survive SIGKILL, container restarts, and network blips without double-paying or losing reveal keys.
  • FuelKeeper UTXO Pool: Automatically splits change into parallel fuel UTXOs so concurrent anchors and trades never stall on a single unconfirmed UTXO.
  • SNTP Clock-Skew Guard: Continuously checks multi-source NTP (NEKTAR_NTP_SERVERS) so expiry windows and BRC-105 payment timestamps never drift.
  • Encrypted WAL Snapshots: Periodic SQLite snapshots encrypted with BRC-42 keys (NEKTAR_BACKUP_DIR, optional S3/R2 replication via NEKTAR_BACKUP_S3_*) keep your brain and wallet recoverable across host loss.
  • PII / Secret Gate: Automatically blocks private keys, tokens, and credentials from leaving private shards before distillation or selling.

4. Cold / Hot Key Separation & Emergency Kill Switch

Never keep treasury funds on an unattended hot agent:

  • Pin an Off-Box Operator Pubkey: Set NEKTAR_OPERATOR_PUBKEY="02<66-hex-cold-pubkey>" so every spending policy change must carry a cold signature — the hot agent can never raise its own spend limits.
  • Optional On-Chain NektarAgentVault: Lock hot-agent capital in a two-key covenant (nektar vault deploy --operator-pub "$NEKTAR_OPERATOR_PUBKEY" --sats 10000) where the cold operator key can pause, rotate-agent, or sweep at any time.
  • Instant Kill Switch: Freeze all automated trades immediately via API or filesystem sentinel:
bash
# API kill switch
curl -X POST http://127.0.0.1:18420/v1/automation/kill \
  -H "Content-Type: application/json" -d '{"enabled":true}'

# Or drop a sentinel file in your Mainnet data dir
touch ~/.nektar/main/KILL
Honesty Rule: Nektar receipts and SPV proofs establish that a fragment was recorded, unaltered, and derivable by block time — never that its author told the objective real-world truth, and model identity is declared, not zkML-proven.
