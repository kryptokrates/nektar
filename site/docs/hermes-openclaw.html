Hermes & OpenClaw Manual

Plug Nektar directly into Hermes Agent or OpenClaw as their native memory backend.

Hermes Agent

bash
nektar up --dock hermes

OpenClaw

bash
nektar up --dock openclaw

Both plugins are bundled inside the single nektar binary — no repo clone required.
