# `NEKTAR_*` environment contract — census

**Convention** (enforced by `check:arch`): every `NEKTAR_*` read goes through the
`@nektar/core` helpers (`nektarEnv`, `setNektarEnv`, `nektarEnvNum`,
`nektarEnvFlag` in `core/src/env.ts`). Raw `process.env.NEKTAR_*` outside
`env.ts` fails the architecture gate — this table is the inventory that gate
protects from drifting.

Secrets accept a `_FILE` twin (`NEKTAR_FUND_WIF_FILE`, `NEKTAR_RPC_PASS_FILE`, …)
resolved by the same helpers — set either, never both. Spend caps use the
`unlimited` opt-out convention: `NEKTAR_DAILY_CAP_SATS` /
`NEKTAR_MAX_SPEND_SATS_PER_DAY` must _all_ read `unlimited` to disable the
guard — a stray numeric cap keeps SpendGuard on (mixed signals never un-guard
a money path). `NEKTAR_MAINNET_CONFIRM=I_UNDERSTAND` is the mainnet ack gate.

Generated 2026-11-13 from a `rg -o 'NEKTAR_[A-Z0-9_]+'` census — 163 distinct
variables. Readers lists the files that reference each var (tests/demos/tools
included — the ambient surface is wider than `packages/*/src` alone).
